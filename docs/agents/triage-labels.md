# Triage 标签

这些技能用五个规范的 triage 角色来描述工作。本文件把这五个角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库中的标签 | 含义 |
| -------------------------- | -------------- | ---- |
| `needs-triage`             | `needs-triage` | 维护者需要评估该 issue |
| `needs-info`               | `needs-info`   | 等待报告者补充更多信息 |
| `ready-for-agent`          | `ready-for-agent` | 已完整定义，可以交给 AFK agent 处理 |
| `ready-for-human`          | `ready-for-human` | 需要人工实现 |
| `wontfix`                  | `wontfix`     | 不会处理 |

当某个技能提到某个角色（例如「打上 ready-for-agent 的 triage 标签」）时，使用本表中对应的标签字符串。

如需改用你实际使用的命名，只需修改「本仓库中的标签」这一列。
